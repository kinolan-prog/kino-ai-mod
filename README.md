# kino-ai-mod

Claude Code 的 mod 合集。

| Mod | 說明 |
| --- | --- |
| [token-meter](./token-meter) | 對話欄上方的 Token 用量儀表板：用量額度、上下文、本回合與累計 token、上下文組成分析、一鍵壓縮、Bash 輸出瘦身 |

## 安裝

在終端機的 Claude Code 對話中輸入：

```
/plugin install token-meter --marketplace kinolan-prog/kino-ai-mod
```

出現「Add marketplace?」時輸入 `y`，接著選擇安裝範圍（直接按 Enter 選 user，所有對話都會載入）。

或在 shell 中執行：

```bash
claude plugin install token-meter --marketplace kinolan-prog/kino-ai-mod
```

在 Claude 桌面版（`/plugin` 無法使用時）：點輸入框旁的 **+** → **Plugins** → **Add marketplace**，輸入 `kinolan-prog/kino-ai-mod`，再按 **Add plugin**。

> 這些 mod 使用 Claude Code 的搶先體驗功能，請先將 Claude Code 更新到最新版本。
